# Restaurant App MVP

A React Native mobile application that allows customers to browse restaurant menus, make reservations, and pre-order food, while providing restaurant managers with digital tools to manage their operations.

## Features

### For Customers

- Browse nearby restaurants
- View digital menus with daily specials
- Check table availability in real-time
- Make reservations with pre-ordering
- Track order status
- View reservation history
  
### For Restaurant Managers

- Manage restaurant profile
- Update digital menu (items, prices, availability)
- Set daily specials
- View and manage reservations
- Process incoming orders
- Update order preparation status
  
## Tech Stack

- **Frontend:** React Native (Expo)
- **Navigation:** React Navigation 6
- **State Management:** React Context API
- **UI Components:** React Native Paper
- **Backend (optional):** Node.js + Express
- **Database:** MongoDB (NoSQL)

## Prerequisites

- Node.js (v14 or later)
- npm or yarn
- Expo CLI (`npm install -g expo-cli`)
- iOS Simulator (Mac) or Android Studio (for emulator)
- MongoDB (if running backend locally)
